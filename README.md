# akl-accessibility-helper
Chrome Extension: currently add Windows accessibility keyboad to right click menu for Chrome Browser
Current is v1.2.2.
Load the folder with developper mode enabled, and pin the extension and do the initial setup according to the menu.
Cannot call app outside chrome so need to register a nativehost with extension ID. So it works.
This extention is for the all those clickers love Chrome with PCs with maybe smaller screens.  
Call the accessibility keyboad with 2 clicks after setup on Chrome browser. But it is the same as 1 double click. ;)
Maybe in the future listed at the chrome web store.
