# Git start

Open Git Bash in this folder, then run:

```bash
git init
git add .
git commit -m "Initial commit: AKL Accessibility Helper v1.2.0"
git tag v1.2.0
git status
```

If Git asks for your name and email:

```bash
git config --global user.name "Tomotoshi Yoshimura"
git config --global user.email "your-email@example.com"
```
